# 🏏 Cricket Team Builder

A responsive Cricket Team Builder website built with **React, TypeScript, and Tailwind CSS**.

## 🚀 Features

- View available cricket players
- Select players for your team
- Track selected players
- Responsive UI
- Newsletter subscription section
- Clean and modern design

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- HTML

## 📦 Installation

```bash
npm install
npm run dev
